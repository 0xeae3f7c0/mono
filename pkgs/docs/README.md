# docs

Documentation site.

Part of the [commit](../../ARCHITECTURE.md) platform (stage: **publish**).
Built with Next.js, Docusaurus, SvelteKit, Astro.

## Develop

```bash
npm ci
npm start
npm run ci   # what CI runs
```

CI: [`.github/workflows/pkg-docs.yml`](../../.github/workflows/pkg-docs.yml), which runs when files in this folder change.
