# widget

Embeddable activity widget (minified by `minify`).

Part of the [commit](../../ARCHITECTURE.md) platform (stage: **show**).
Built with Vue.

## Develop

```bash
npm ci
npm run dev
npm run ci   # what CI runs
```

CI: [`.github/workflows/pkg-widget.yml`](../../.github/workflows/pkg-widget.yml), which runs when files in this folder change.
