# edge-cache

Edge KV cache for badges and status.

Part of the [commit](../../ARCHITECTURE.md) platform (stage: **serve**).
Built with TypeScript, Hono, Workers.

## Develop

```bash
npm ci
npm run ci   # what CI runs
```

CI: [`.github/workflows/pkg-edge-cache.yml`](../../.github/workflows/pkg-edge-cache.yml), which runs when files in this folder change.
