# admin-api

Team and repository ownership API for the admin console.

Part of the [commit](../../ARCHITECTURE.md) platform (stage: **show**).
Built with NestJS.

## Develop

```bash
npm ci
npm start
npm run ci   # what CI runs
```

CI: [`.github/workflows/pkg-admin-api.yml`](../../.github/workflows/pkg-admin-api.yml), which runs when files in this folder change.
