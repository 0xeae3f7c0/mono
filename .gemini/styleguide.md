# Review style guide

This is a monorepo: a Rust CLI in `crates/`, projects in `pkgs/`, repository
tooling in `scripts/` and GitHub Actions workflows in `.github/workflows/`.

Focus reviews on correctness, security and maintainability. Formatting and
lint (rustfmt, clippy, actionlint, generated files) are enforced by CI, so do
not comment on them.

## Conventions

- Commit messages and pull request titles follow Conventional Commits.
- Workflows: actions are pinned to a full commit SHA with a `# vX.Y.Z`
  comment; top-level `permissions` is `contents: read` and write permissions
  are granted per job. Flag any unpinned action or broader permission.
- Never interpolate untrusted event data (titles, bodies, branch names)
  directly into `run:` scripts; pass it through `env:`.
- Secrets must only come from `secrets.*`; never hard-code tokens or keys.
- Files generated by `scripts/gen-pkg-workflows.mjs` and
  `scripts/gen-catalog.mjs` are not edited by hand.
- Only add dependencies that are actually used.
