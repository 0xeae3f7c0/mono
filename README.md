Hello!

`commit` is a self-hosted engineering-activity platform: it collects what happens in
your repositories, analyzes it, and shows it back through dashboards, badges, apps and a
weekly report. This monorepo holds every part of it.

## Start here

- [`ARCHITECTURE.md`](ARCHITECTURE.md): how the projects fit together, and what each one does.
- [`CONTRIBUTING.md`](CONTRIBUTING.md): how a change lands in this repository.
- [`Documentation`](doc/README.md): layout, running locally, automation and repository settings.
